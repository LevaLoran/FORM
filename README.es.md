## Por qué FORM.

La mayoría de las listas de tareas terminan en una casilla. FORM. convierte el mismo trabajo diario en una mejora a largo plazo: XP, rangos, árbol de habilidades, logros y **tareas compartidas** con amigos. Interfaz limpia, temas claro y oscuro.

## Funciones

- Tareas únicas y diarias, deshacer completado, 11 rangos, árbol de habilidades (6 ramas × 4 niveles × 6 grados)
- Calendario, mapa de calor, historial, reinicio de XP por periodo
- Cuenta GitHub o correo, sincronización en la nube, copias de seguridad, exportar/importar
- FORM ID, amigos, perfil público, privacidad, tareas compartidas
- 12 idiomas, barra de progreso, PWA instalable

## Empezar

1. Abre [https://levaloran.github.io/FORM/](https://levaloran.github.io/FORM/)
2. Elige el idioma
3. Inicia sesión con GitHub o correo
4. Añade una tarea y márcala como hecha

En el móvil: «Añadir a la pantalla de inicio» o «Instalar aplicación».

Local: `python -m http.server 8000`. Configuración del servidor: [README.md](README.md#owner-setup-supabase).
