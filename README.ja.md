## なぜ FORM. か

普通の ToDo はチェックで終わります。FORM. は同じ日常を長期の成長に変えます。XP、ランク、スキルツリー、実績、友だちとの**共同タスク**。UI は落ち着いたライト／ダークテーマです。

## 機能

- 一度きり／毎日のタスク、完了の取り消し、11 ランク、スキルツリー（6 系統 × 4 段階 × 6 レベル）
- カレンダー、ヒートマップ、履歴、期間指定の XP リセット
- GitHub またはメール、クラウド同期、バックアップ、インポート／エクスポート
- FORM ID、友だち、プロフィール、プライバシー、共同タスク
- 12 言語、進捗バー、インストール可能な PWA

## はじめ方

1. [https://levaloran.github.io/FORM/](https://levaloran.github.io/FORM/) を開く
2. 言語を選ぶ
3. GitHub またはメールでログイン
4. タスクを追加して完了する

スマホではホーム画面に追加／アプリをインストール。ローカル: `python -m http.server 8000`。サーバー設定は [README.md](README.md#owner-setup-supabase)。
