## Зачем FORM.

Обычные списки дел заканчиваются галочкой. FORM. превращает ту же рутину в долгосрочную прокачку персонажа: задачи дают XP и очки навыков, ранги растут от «Новичка» до «Легенды», открывается дерево навыков, награды и совместные задания с друзьями. Интерфейс спокойный — светлая и тёмная темы, без визуального шума.

## Возможности

**Задачи и прогресс** — разовые и ежедневные задачи, отмена выполнения, до 10 задач в день, 11 рангов, дерево навыков (6 веток × 4 ступени × 6 уровней), 7 наград.

**Статистика** — календарь, тепловая карта за 12 месяцев, история, отчёт за день, сброс XP за 7 / 30 / 365 дней.

**Аккаунт** — вход через GitHub или почту, синхронизация между устройствами, офлайн-очередь, резервные копии, экспорт/импорт, аватар любого размера.

**Социальное** — постоянный FORM ID, друзья, заявки, профиль с баннером и рамкой, приватность, **совместные задания** с общим прогрессом и наградой.

**Интерфейс** — нижняя навигация + чипы сверху, мини-панель прогресса, 12 языков, светлая/тёмная тема.

## Как считается прогресс

| Правило | Значение |
| --- | --- |
| XP | 5 за задачу |
| Лимит | до 10 задач в день |
| Ранги | 11 ступеней (`rankThresholds` в `app.js`) |
| Навыки | очко ветки за выполненную задачу своей категории |
| Серия | дни подряд с хотя бы одной задачей |
| Награды | не снимаются при отмене или сбросе XP |

## Быстрый старт

1. Откройте [https://levaloran.github.io/FORM/](https://levaloran.github.io/FORM/)
2. Выберите язык
3. Войдите через GitHub или создайте аккаунт по почте
4. Добавьте задачу и отметьте выполнение

На телефоне: «Добавить на главный экран» (iOS) или «Установить приложение» (Android / Chrome).

## Локальный запуск

```bash
python -m http.server 8000
```

Откройте `http://localhost:8000`. Для входа и синхронизации нужны ключи Supabase в `config.js` (см. [English README → Owner setup](README.md#owner-setup-supabase)).
