## Навіщо FORM.

Звичайні списки справ закінчуються галочкою. FORM. перетворює ту саму рутину на довгострокову прокачку: завдання дають XP і очки навичок, ранги — від «Новачка» до «Легенди», є дерево навичок, нагороди та спільні завдання з друзями. Інтерфейс спокійний: світла й темна теми.

## Можливості

- **Завдання** — разові та щоденні, скасування виконання, до 10 на день, 11 рангів, дерево навичок (6 гілок × 4 ступені × 6 рівнів)
- **Статистика** — календар, теплова карта, історія, скидання XP за період
- **Акаунт** — GitHub або пошта, хмарна синхронізація, резервні копії, експорт/імпорт
- **Соціальне** — FORM ID, друзі, профіль, приватність, **спільні завдання**
- **Інтерфейс** — 12 мов, світла/темна тема, міні-панель прогресу

## Швидкий старт

1. Відкрийте [https://levaloran.github.io/FORM/](https://levaloran.github.io/FORM/)
2. Оберіть мову
3. Увійдіть через GitHub або пошту
4. Додайте завдання й відмітьте виконання

На телефоні: «На початковий екран» або «Встановити застосунок».

Локально: `python -m http.server 8000` → `http://localhost:8000`.
