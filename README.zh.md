## 为什么是 FORM.

普通待办只到勾选为止。FORM. 把同样的日常变成长期成长：经验值、段位、技能树、成就，以及与好友的**共同任务**。界面克制，支持浅色/深色主题。

## 功能概览

- 单次与每日任务、撤销完成、11 个段位、技能树（6 分支 × 4 阶 × 6 级）
- 日历、热力图、历史、按周期重置 XP
- GitHub 或邮箱登录、云同步、备份、导入导出
- FORM ID、好友、公开主页、隐私、共同任务
- 12 种语言、进度条、可安装 PWA

## 快速开始

1. 打开 [https://levaloran.github.io/FORM/](https://levaloran.github.io/FORM/)
2. 选择语言
3. 使用 GitHub 或邮箱登录
4. 添加任务并勾选完成

手机：添加到主屏幕 / 安装应用。本地：`python -m http.server 8000`。服务端配置见 [README.md](README.md#owner-setup-supabase)。
