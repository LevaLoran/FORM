# FORM 1.0.2 — RPG Evolution & Stability

Дата: 23 ноября 2026.

## Изменения
- Новый круговой обзор навыков с шестью прежними категориями, окрашенными секторами и текущим прогрессом.
- Расширенная RPG-прокачка: 8 ступеней × 6 уровней на каждое направление с сохранением очков, рангов и прогресса.
- Переход из уведомлений в конкретное совместное задание или окно принятия приглашения.
- Ролевые кнопки выполнения, отмены, удаления, выхода и скрытия завершённых заданий только у себя.
- Исправлена нормализация серверной темы для градиента и ASCII/двоичного декора баннера.
- Персональное скрытие завершённых совместных заданий в Supabase с RLS.
- Обновление кэша PWA и версии FORM.

## Проверки
Проверка синтаксиса JS-файлов через Node.js; изолированный тест радиального UI в Chromium; тест интерфейса совместных заданий с имитацией Supabase, проверка миграции и RLS в рабочем Supabase.

## Ограничения
Не проверены реальная совместная работа двух аккаунтов, вход через GitHub OAuth, PWA без сети и Android APK. Supabase security advisor обнаруживает предупреждения в старых функциях; полный аудит безопасности не завершён. Не считать отсутствие ошибок гарантированным.

## Развёртывание
GitHub Pages получает файлы из ветки main. SQL-миграция уже применена к подключённой базе Supabase FORM. Для другой базы применить supabase/migrations/20261123_form_1_0_2_banner_and_task_visibility.sql.
